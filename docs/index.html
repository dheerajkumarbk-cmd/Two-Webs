Two Webs

Websites are starting to hand AI assistants a different page than they hand people. We measured how often, what triggers it, and what happens to the facts.

Every number on this page is an automatic count from one crawl of high-traffic sites on 14–15 November 2026, from one network location in India. Nothing here has been hand-labelled yet. Rates are per site, with 95% Wilson intervals.

One header is enough

Earlier tools test for a second web by pretending to be an AI crawler: they change the User-Agent. We also tested a normal browser that adds a single header, Accept: text/markdown, the way some agent tools ask for pages. The same sites, the same minutes, each request sent twice.

What the Markdown twin does to the facts

For each twin we extracted the numbers, prices, percentages and dates stated in the human page and checked which of them survive in the version served on request. A fact counts as lost only if it appears in both browser fetches and in neither Markdown fetch.

We do not report a rate for facts added by the twin. The extractor counts page metadata, postcodes and phone numbers as "added facts", so that count is not yet meaningful. Individual added claims are shown below as examples only.

What sites say only to the machine

"Shown to people" is the raw HTML a browser receives before any JavaScript runs. Text that a page adds with JavaScript is not captured, so a sentence listed as machine-only may still be visible in a rendered browser.

How it works

  • Five identities per page, twice each, interleaved: browser; an identical control; browser + Markdown Accept; an AI fetcher's User-Agent; AI User-Agent + Markdown Accept.
  • Noise rule: content counts as machine-only only if it is in both fetches under that identity and in neither browser fetch.
  • Built-in control: the control sends exactly the browser's headers. Whatever "difference" it shows is the method's false-positive floor, measured in the same run.
  • No model in the loop: text extraction and fact extraction are plain rules, so results are reproducible on a laptop CPU.

Limits

  • Automatic labels only. The "addressed to AI" label over-fires on pages that merely mention AI agents; two people still need to label the flagged cases.
  • A lower bound on User-Agent cloaking: sites that verify AI fetchers by IP address show us the human page.
  • Raw HTML, homepage plus one inner page, one day, one location. Country redirects are a known confound.
  • Sites that disallow an identity in robots.txt were skipped for that identity.
  • Which real assistants send the Markdown header is not established here.
