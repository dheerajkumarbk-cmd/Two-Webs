Method and limits

  • Noise rule. A sentence or fact is machine-only only if it is in both fetches under that identity and in neither browser fetch. Human-only is the mirror.
  • Twin. The browser receives HTML and the other identity receives a non-HTML rendition at the same address.
  • Interval for pooled fact loss. Facts on one page are not independent, so the interval resamples sites (5,000 bootstrap draws), not facts.
  • Labels are automatic. "Addressed to AI" matches phrases such as "AI agents" and over-fires on vendors that sell agent products.
  • Raw HTML. A fact counted as lost is lost relative to raw HTML. Text that people see only after JavaScript runs is not captured on either side.
  • Not established: which deployed assistants send the Markdown Accept header, and how often.
  • Sites that disallow an identity in robots.txt were skipped for it. User-Agent results are a lower bound, since IP-verifying sites show us the human page.
